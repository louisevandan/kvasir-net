# 결정론적 실행 장부

이 문서는 반복 실행에서 얻은 사실을 다음 단계의 사전 차단으로 재사용하는 활성 장부다. 역사 보고는
원문 증거를 소유하고, 이 장부는 아직 적용 중인 교훈과 실행 전 확인 수단만 소유한다. 오류를 경험했다는
사실만 적지 않는다. 모든 항목은 원인 증거, 자동 차단 경로, 재사용 지점을 함께 가진다.
