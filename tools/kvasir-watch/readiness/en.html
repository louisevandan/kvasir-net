Checked directly on the MI250 hosts today

  • The engine hosts are alive. On both MI250 machines the linker hub answers 200 at 127.0.0.1:19001, and MI250-01 also runs p4-agent and two p4_staged_serve workers.
  • The public outage is exposure, not compute. A cloudflared tunnel has run on MI250-01 since Aug 25, but it logged no request today; its last errors (Sep 16) were "unable to reach the origin service". The settlement gateway has no listening port, which matches the owner's decision to stop it until it is ported to p4.
  • GLM-5.2: the complete 492 GB GGUF set is on MI250-02, and the hub's own inference history holds only Step-3.7-Flash runs. Container logs and the system journal show downloads and mounts, no GLM load. The evidence for the GLM claim is therefore somewhere else, and needs to be published.
  • Step-3.7-Flash is the largest model actually measured — 428B MoE (45 layers, 288 experts per layer, top-8), Q4_K_XL at 114 GiB, on MI250 (gfx90a) 8 GCD × 2 machines with 200G InfiniBand. The deck said ~201B; it now says 428B.
  • Operational hygiene: the tunnel token is visible in the process list on MI250-01.

Read these before quoting any number

  • The control loop has a single point of failure. The I1 run was driven from one Windows PC. When it shut down, the collector and return tunnels died with it. The fix under way is a remote supervisor that keeps running on the hosts (R1).
  • "3/3 correct" needs a note. On the medium and long requests the model's arithmetic was wrong; a deterministic step outside the model produced the returned answer.
  • There is no single-host baseline yet, and GPU utilisation is low (Macs 3–5%, MI250s 6–10%).
  • The transport has no TLS or node authentication. It assumes a trusted LAN, so it is not ready for untrusted DePIN operators. Swarm, mobile nodes, wallet, KVR and gateway live in the kvasir-net code, not in p4.
  • The process is disciplined and AI-driven: sealed runs, mutation checks and preserved failures. Weak spots: no CI, a bus factor of one operator, and a canonical repo that stays in Korean. The public branch was translated and needs re-syncing.
