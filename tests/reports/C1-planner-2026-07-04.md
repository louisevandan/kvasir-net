# Test Report — C1 capacity planner

- Date: 2026-07-04
- Tool: `controller/planner.py` in `linkcpp-controller` image (python + gguf)
- Reads real GGUF metadata + tensor byte sizes; no runtime needed.

## Cases (real models)

| Case | Input | Result |
|------|-------|--------|
| 32B feasible | Qwen2.5-32B, nodes 14G/22G, ctx 8192, par 4 | FEASIBLE; weights 18.48 GiB, **KV 8.0 GiB** (matches hand calc); split [30,34]; node0 13.95/14, node1 15.54/22 |

## Verified behaviors

- Correct GGUF introspection: arch, n_layer, n_kv_head, head dims, per-layer weight
  bytes, MoE expert bytes.
- KV math `2·n_kv·head_dim·dtype·n_layer·ctx·parallel` matches by-hand values and scales
  with parallelism (2→8→32 GiB at par 4→16).
- Resource-aware contiguous placement; escalates a node to expert→CPU when VRAM is tight
  and RAM allows; emits `tensor_split` and per-node `-ot`.
- INFEASIBLE verdict names the shortfall (VRAM vs budget, KV share) and suggested knobs.
