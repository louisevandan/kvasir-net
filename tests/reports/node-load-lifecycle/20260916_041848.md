## 구현 판정

- Rust event-drive는 별도 CREATE/DELETE 없이 Agent-target `NODE_LOAD`로 노드를 만들고
  `NODE_UNLOAD`의 typed `succeeded/absent`로 제거한다. Agent source가 같은 여러 결과는
  causation ID로 요청 node에 결속한 뒤 node/generation/adapter/content identity를 다시 검사한다.
- 다중 LOAD 중 하나가 거부되면 이미 성공한 node만 OUTER가 개별 UNLOAD한다. 첫 실패와 cleanup 실패를
  분리하고 성공하지 않은 node를 회수 성공으로 기록하지 않는다.
- HF Qwen controller와 lifecycle 검증기는 정상 UNLOAD와 불명 상태 abort를 모두 Agent lifecycle로
  보낸다. direct command 우회는 거부하고 `owned`/`ready`는 typed 자원 상태로만 제거한다.
- Agent event runtime의 legacy CREATE/DELETE 수용 분기를 제거했다. 정상 제품 경로의 검색 결과에는
  구 content type이 없으며, 두 문자열은 무효과 거부 시험에만 남는다.
- HF control-plane import는 모델 package를 요구하지 않는다. safetensors는 실제 tensor `step`에서만
  불러오며 `-I -S` 격리 import 반례로 이 경계를 고정했다.

모델·interpreter/dependency·포트·Agent/adapter binary·node 잔량을 하나의 preflight로 먼저 봉인한다.
