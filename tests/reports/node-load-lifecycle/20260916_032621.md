## 구현 판정

- llama.cpp actual retained worker가 Agent 수명 Event의 LOAD/UNLOAD를 실행하고 typed terminal을
  Agent로 돌려준다. 첫 blocking 입력과 후속 drain이 같은 퇴역 경로를 사용한다.
- llama.cpp 시작 실패와 UNLOAD 실패는 native cleanup 결과에 따라 `Absent`와 `Unknown`을 구분하며
  first error와 cleanup error를 보존한다.
- HF는 supervisor Agent와 추론의 OUTER owner를 분리한다. 실제 Python child의 LOAD/UNLOAD 결과를
  typed terminal에 결속하고 native response 보존량을 retention snapshot에 포함한다.

  효과 전에 기다리며 원 input을 보존한다.
- HF는 Python frame에 512-byte typed wrapper 여유를 native 효과 전에 함께 예약한다. Python 응답은
  1,024-byte 상한 안이지만 wrapper 결합 결과가 이를 넘는 실제 child UNLOAD도 Agent terminal을 잃지 않는다.
