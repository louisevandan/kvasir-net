# Release A H0 v8 — Sealing the pre-run contract before the I1 real-hardware run

Status: non-model gates GREEN. The I0 v8 real-hardware re-run and the I1-Q64 real-hardware run are not run yet. Product-wide `integrity_baseline=false`.

## Cause and change

A static cross-check after I0 v7 found that the existing H1/I1 generators do not put the LOADED, INFERENCE_WINDOW and DRAINED observation barriers into the run configuration. In addition, the I0 collector's 60-second limit on reading remote artifacts cannot guarantee delivery of the long-running raw data for 64 cases. [L086](../../../docs/deterministic-execution-register.md) was pinned with a new preflight and mutation tests, and the defect was blocked before model loading.

[H0 v8](../../../test/benchmarks/cluster-inference/release-a/benchmark-spec-qwen122b-h0-v8.json) keeps Rust runtime source `b8f5214ba9a88a2bc449889af80aff4b2c3ae8c0` and the existing 3-host binaries, model and partitioning. The new I1 runner, evidence builder and judge, and the changes to the H1 materializer and I0 collector, are bound by file SHA. The source bundle is `925ca6af156ab6a259ee1c7e1b0682626ef0c2a9 HEAD`, 5,329,168 bytes, SHA-256 `7694d1458d33f7259bfbe209470128945cee6af2a53572f7e17f69b86b5bb554`, and it passed `git bundle verify`. The H0 v8 specification SHA-256 is `9dd17f0a2a0a86f1d56937d0ccf77c54c1d0934c8e1b1298eef2dd61e951d189`.

Before LOAD, H0 v8 checks the 64 cases (short32/medium16/long16), the original prompts, JSON oracles, processors and deadlines, 15,000 ms each for LOADED, inference start and DRAINED, and 900 seconds for I1 artifact transfer. The full 64-case synthetic path verifies source/model output provenance, every RELEASE, stage/batch/GPU/reclaim evidence, and a scorecard that counts only short cases as useful model tokens.

## Non-model checks run

- `python test/benchmarks/cluster-inference/release-a/verify-h0-v8.py`: 21 fixed checks passed. They include these tests: H1 materializer 10, I0 runner 7, I1 runner 9, I1 raw builder 5, I1 judge 3, 64-case full path 5, benchmark spec 4.
- In the 64-case full path, the mutations for a missing request, a wrong answer, a missing processor and missing GPU samples were each rejected. Missing or 0 observation barriers in the spec, a short I1 artifact transfer limit, and missing case/oracle binding were also rejected.
- `git bundle verify target/p4-h0-v8-source-925.bundle`: done. This bundle and the specification are preserved in the locally ignored `target/`.

## Real-hardware entry conditions and next action

This result proves the pre-run contract; it is not I1 acceptance or a performance improvement. I0-S/M/L must be re-run on the same 3 physical hosts with the changed final source. The preflight includes a round trip to the new task agent's actual advertised address, nodes/native child 0 on the three hosts, preservation of the protected agents, the four controller tunnel PIDs/commands, and the 17 binding hashes. Only after I0 passes correct answers, EOS, RELEASE and reclaim again does the single LOAD of I1-Q64 start. I1 judges 64/64 normal responses and the raw data/scorecard within the same inference window.
