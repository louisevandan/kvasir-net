## Code comparison and implementation

| Requirement | Existing code | Final change |
| --- | --- | --- |
| OUTER knows the full topology and chooses an ingress agent per commission | source/target/OuterEndpoint were already separate | The contract separates placement authority from the ingress path. Node-to-node delivery goes straight to target; only OUTER-bound traffic goes through the ingress agent |
| Every derived event carries a return route from the first input | The real OUTER sender sets Some, but the common validate allowed None | P4E3 encode/decode, the broker and both adapters' offer reject missing or contradictory routes before execution |
| Identity of the OUTER endpoint and the route | Only channel/generation validity was checked | If source/target is Outer, ingress, channel and generation must all equal return_route |
| Explicit reply target | control/HF/llama fell back to source when None | Fallback removed. The common ReturnContext owns validation and reply envelope construction |
| Normal node delivery | Envelope::next copied the context | Behavior kept, pinned by a wire hop and a real retained worker mutation |
| Per-request return in mixed batches | llama parsed and assembled ReplySpec separately | The existing opaque owner wire is kept and converted to and validated as a P4 ReturnContext. OUTPUT/RELEASE use the selected owner's route/correlation/deadline; causation keeps the actual carrier |
| OUTER receive validation | HF Python compared only target | Agreement between return_route and the OUTER source is also checked before the trace is accepted |

The common protocol takes on no new dependency on model/batch/native types or serde. ReplySpec is an adapter wire codec.
P4 does not read opaque batch payloads. The existing per-stream observation keeps the complete per-OUTER-route aggregation and
the explicit owned-request marking. This work does not change the cancelled monitoring UI or aggregation method.

The Rust Option and P4E3 field layout are kept. None can represent an originally rejected input but is not a valid event.
Existing valid P4E3 bytes are unchanged, and older peers that omitted the route must be fixed. No unconditional backward compatibility is claimed.
Socket binding and outbound/local classification in the ingress agent use the earlier `434bd97fc` implementation. Source authentication is separate.
