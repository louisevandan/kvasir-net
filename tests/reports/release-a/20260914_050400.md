# Release A — native 비용 관측 연결

2026-09-14 05:04 KST. 기준 P4 `b25e714c7`에서 A0 계측을 추가했다. **CPU 실제 경로 conformance PASS이며 A0 완료나 제품 수용은 아니다.**
[계획](../../plans/release-a-20260914.md) · [이전 native 회귀](20260914_043652.md).

## 변경과 소유권

`P4_STAGED_TRACE_COST=1`에서만 native stderr에 호출/실행/graph 비용을 기록한다. 기본 비활성이다.
server는 실제 physical execution/load/session과 호출을 결속하고 parse/match/sample/encode를 기록한다.
runtime은 setup/decode/capture/post와 회수 bytes를 분리한다. decode 안의 capture를 중복 합산하지 않는다.
upstream stage_hook은 context/graph identity, 실제 KV extent·mask allocation, graph setup/input/실행을 관측한다.
일반 attention과 Nemotron의 hybrid 입력 경로를 포함한다. hybrid의 실모델 관측은 아직 미실행이다.
graph 실행 시간은 명시 backend synchronize를 포함하며 dispatch·내부 복사와 순수 kernel을 구분하지 못한다.
graph와 native decode는 겹치는 계층이므로 합산하지 않는다. cross-host transit과 pure kernel은 null이다.

현재 pin `451b89bae0c4b1dd612eb503ceace906c01ddcc9`, 28-patch SHA
`a07b782641a008bcab4b4e81e58cd11798387c5bf332fa4a0474a1dce4d700ef`.
`0029-cost-observation.patch`는 과거 제거된 모델 지원 패치와 별개인 관측 패치다.
공개 ABI·정책·원장·sampling 기본값은 변경하지 않았다. private 접근은 기존 upstream/compat 경계 안이다.

## 실패·미완 경계

최초 patch 생성은 Windows cp949 decode, 준비 명령은 잘못된 scripts/upstream 경로로 실패했다.
UTF-8 및 실제 scripts 경로로 수정했다. 최초 환경 배열은 PowerShell flatten으로 config parse에서 거부됐다.
첫 정상 요청은 stderr 상속이 꺼져 로그가 없었다. 이전 연결을 재사용한 변이 준비는 duplicate suppression에
걸렸고 보존했다. 이후 fresh agent/독립 log로 실행했다. 실패 입력·정답·기한을 완화하지 않았다.
이 준비 실패들을 제품 SLO arm이나 성공 실행으로 집계하지 않는다.

helper는 자신이 만든 agent만 종료한다. agent 종료는 native graceful 회수의 증거가 아니며 실제 driver의
UNLOAD/DELETE 및 completed/released artifact와 구분한다. 원격 기존 프로세스는 변경하지 않았다.
Rust production은 그대로이므로 전체1451/0/7은 앞선 동일 Rust 소스 검증이다. 이번에 재집계하지 않았다.
HF Python은 앞선 실제 FP32 교차 실행·취소14 logits/28 cache 비교 PASS가 유지되며 이번 계측은 llama 경로 변경이다.

550B의 실제 hybrid 관측·occupancy/CPU expert 배치별 비용·계측 overhead·Worker/client/network 결속,
완전한 native PLAN 상한·A1–A5·7-host SLO/H0–H7은 남아 있다. CUDA 빌드는 진행 중이며 아직 수용 증거가 아니다.
