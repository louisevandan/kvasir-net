## Changes and ownership

Only with `P4_STAGED_TRACE_COST=1` does native write call/execution/graph costs to stderr. It is disabled by default.
The server binds calls to the actual physical execution/load/session and records parse/match/sample/encode.
The runtime separates setup/decode/capture/post and the reclaimed bytes. Capture inside decode is not summed twice.
The upstream stage_hook observes context/graph identity, the actual KV extent and mask allocation, and graph setup/input/execution.
It covers both the ordinary attention input path and Nemotron's hybrid input path. Real-model observation of hybrid has not been run yet.
Graph execution time includes an explicit backend synchronize and cannot separate dispatch and internal copies from the pure kernel.
Graph and native decode are overlapping layers, so they are not summed. cross-host transit and pure kernel are null.

Current pin `451b89bae0c4b1dd612eb503ceace906c01ddcc9`, 28-patch SHA
`a07b782641a008bcab4b4e81e58cd11798387c5bf332fa4a0474a1dce4d700ef`.
`0029-cost-observation.patch` is an observation patch, separate from the model support patch removed earlier.
The public ABI, policy, ledger and sampling defaults were not changed. Private access stays within the existing upstream/compat boundary.

## Failures and open boundaries

The first patch generation failed on a Windows cp949 decode, and the prepare command failed on a wrong scripts/upstream path.
These were fixed to UTF-8 and the real scripts path. The first environment array was rejected at config parse because of PowerShell flattening.
The first normal request had no log because stderr inheritance was off. A mutation preparation that reused an earlier connection hit duplicate suppression,
and that was preserved. After that, runs used a fresh agent and an independent log. Failing inputs, correct answers and deadlines were not relaxed.
These preparation failures are not counted as product SLO arms or successful runs.

The helper stops only the agents it created. Agent exit is not evidence of native graceful reclaim and is kept distinct from the actual driver's
UNLOAD/DELETE and the completed/released artifact. No existing remote process was changed.
Rust production is unchanged, so the full 1451/0/7 is verification of the same earlier Rust source. It was not recounted this time.
For HF Python, the earlier real FP32 cross-run and cancel 14 logits/28 cache comparison PASS still stands; this instrumentation is a llama path change.

Still open: real hybrid observation on 550B, per-batch occupancy/CPU expert cost, instrumentation overhead, Worker/client/network binding,
complete native PLAN limits, A1–A5 and 7-host SLO/H0–H7. The CUDA build is in progress and is not acceptance evidence yet.
