## 대상과 변경 범위

실제 `S:/models/unsloth/Qwen3.5-122B-A10B-MTP-GGUF/`에서 UD-Q5_K_S 3shard를 확인했다.
총88,310,156,320byte다. 첫 shard가 약11MB인 것은 관측 파일 크기이며 이름만으로 결손을 판정하지 않았다.
각 GGUF header의 split.count=3, split.no=0/1/2를 확인했다. mmproj는 텍스트 서비스 대상에서 제외한다.
metadata는 qwen35moe, block_count49, nextn_predict_layers1이다. 실제 native PLAN 로그에서도
n_layer48/n_layer_all49를 확인했다. 파일에 MTP가 포함돼도 A는 spec_type=none이며 새로운 MTP 수용을 주장하지 않는다.

새 artifact/corpus/PLAN/layout을 사용한다. 550B의108layer·7host/8stage를 복사하지 않는다.
기존 Qwen5host/6stage의 [0,8),[8,16),[16,29),[29,37),[37,45),[45,48)도 시작 후보일 뿐이다.
과거 resident4·서로 다른 KV 형식의 실행을 새 resident8/context102400/F16 수용으로 전용하지 않는다.
최소2물리 host에서 공유 pool·device identity·native allocation·비용을 확인해 topology를 봉인한다.

resident8, context102400, 전체819200, F16 K/V, batch/ubatch128/64, 출력2048, 8wave와 기존
short/medium/long의 입력 길이·정답·SLO·취소/회수 기준은 유지한다. 대상 변경은 새 명세이며
550B의 실패를 통과로 다시 판정하지 않는다. 원본550B 증거는 보존하고 그 재적재/재실행은 새 대상의
선행 조건에서 제외한다. HF 소형 실기 회귀도 유지하며122B GGUF의 실행을 HF122B 지원으로 세지 않는다.

## 로컬 native PLAN

native SHA256 `97003fc1077f18b34d7718c105da50e3e89323f99c6052ca11149268cc595aba`로
[37,45) 8개 base layer·RTX3090 CUDA0·sequence8·context819200·F16 K/V·batch128/ubatch64의
실제 `--inspect-memory-plan`을 실행했다. exit0, complete=true, fits_current_free=true다.
GPU model14,132,488,192/context3,563,847,680/compute189,139,072byte, 합계17,885,474,944byte,
host compute105,646,112byte를 보고했다. 실제 weights/KV 적재나 분산 추론은 실행하지 않았다.

native의 unified execution_shape는 n_ctx=819200/n_ctx_seq=819200이다. 이를 요청마다102400을
native가 독립 강제했다는 증거로 읽지 않는다. 요청별 논리 한도·공유 pool·전체 cut·allocation 검증은 남는다.
장치명과 PCI 순서 확인 뒤 CUDA0 RTX3090을 선택했고 RTX4080의 별도 작업은 유지했다.
899개 tensor의 이름 중복·미지정 타입0 및 shard header 일관성도 검사했다. 저장 tensor bytes는
KV/scratch나 실제 allocation이 아니므로 전체 배포 profile 수용으로 세지 않는다.

`local-candidate-plan.json`·`local-candidate-plan/result.json`·stderr.log와
`candidate-storage-geometry.json`이 소유한다. 재현은 다음 명령이다.

```powershell
python test/benchmarks/cluster-inference/release-a/probe-memory-plan.py --config target/release-a-qwen122b-20260915/local-candidate-plan.json --output <새-plan-디렉터리> --expect-device "NVIDIA GeForce RTX 3090"
```
