# Release A target change — Qwen3.5-122B-A10B

2026-09-15 KST. Baseline `67c722325`, Windows PowerShell. At the user's direction, 550B was dropped and the target specification
and preparation work were switched to Qwen122B. The [stage plan](../../plans/release-a-20260914.md),
[development scope](../../../docs/external-analysis-improvement-plan.md#release-a) and
[verification contract](../../../docs/distributed-batching-verification.md#release-a-contract) were updated together.
**This is a target switch and corpus preparation; it is not completion of model LOAD, inference or service acceptance.**

## Target and scope of change

The UD-Q5_K_S 3 shards were confirmed in the actual `S:/models/unsloth/Qwen3.5-122B-A10B-MTP-GGUF/`.
The total is 88,310,156,320 bytes. The first shard being about 11MB is the observed file size; no truncation was judged from the name alone.

The metadata is qwen35moe, block_count 49, nextn_predict_layers 1. The actual native PLAN log also
confirmed n_layer 48/n_layer_all 49. Even though the file includes MTP, A uses spec_type=none and claims no new MTP acceptance.

A new artifact/corpus/PLAN/layout is used. The 550B's 108 layers and 7 hosts/8 stages are not copied.
The existing Qwen 5-host/6-stage split [0,8),[8,16),[16,29),[29,37),[37,45),[45,48) is also only a starting candidate.
Earlier runs with resident 4 and different KV formats are not reused as acceptance of the new resident 8/context 102400/F16.
The topology is sealed after confirming the shared pool, device identity, native allocation and cost on at least 2 physical hosts.

resident 8, context 102400, total 819200, F16 K/V, batch/ubatch 128/64, output 2048, 8 waves, and the existing
short/medium/long input lengths, correct answers, SLO and cancel/reclaim criteria are kept. The target change is a new specification and
does not re-judge the 550B failures as passes. The original 550B evidence is preserved, and its reload/rerun is removed from the
prerequisites of the new target. The small HF real-hardware regression is also kept, and a run of the 122B GGUF does not count as HF 122B support.
