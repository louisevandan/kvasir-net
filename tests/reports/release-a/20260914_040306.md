## A-RED

기준 시험은 timer 단독1, scheduler33, bounded10, service2, model-loading34, composer4가 모두 통과했다.
과거 RED를 현재에서도 항상 재현된다고 주장하지 않는다. 원래 시험은 `decode_coalescing_wait`와
`before_native_issue` 사이에 정상 RELEASE가 처리되어도 전역 상태가 같아야 한다고 비교했다.
실제 Worker의 tail RELEASED를 보류/전달해 다음 두 경우를 분리했다.

- 입력 없이 timer 만료: 기존 request/flight/slot/input authority와 batch ordinal이 정확히 동일해야 한다.
- 정상 RELEASE interleave: 실제 완료 peer의 slot 하나 반환과 OUTER receipt용 event 하나만 허용한다.
  RELEASE commit 시점에서 나머지 authority는 동일해야 한다. 이후 timer 만료도 추가 권한을 만들지 않는다.

두 경로는 underfull decode 실제 발행·outstanding 중 재발행 금지·최종 회수까지 검사한다.
runtime timer/기본 정책을 변경하지 않았다. fake native를 쓰는 실제 Worker loop 시험이며 원격 native 실기와 구분한다.
작성 중 `sequence_id`의 Option 타입 compile 오류 한 건을 수정한 뒤 검증했다.

start→end는 native RPC와 capsule decode를 포함하므로 pure kernel로 부르지 않는다.
