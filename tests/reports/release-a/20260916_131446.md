## Tests pinned first

The [execution plan](../../plans/release-a-integrity-first-20260916.md) and the
[machine-readable contract](../../../test/benchmarks/cluster-inference/release-a/integrity-test-spec-qwen122b-i0-v1.json)
pin the following 14 arms.

- I0: 3 single requests (short/medium/long) on the current source.
- I1: 64 normal corpus cases, closed-loop, in the same load.
- I2: cold8, sustained8×8, same-load recovery3×8.
- I3: overload80, cancel, slow/disconnected edge, middle-stage restart, late old-generation return.
- I4: same-load 32×8, a soak of at least 93 minutes, and reclaim through a normal NODE_UNLOAD.

Every arm requires not only per-request normal response, EOS, deadline, terminal and RELEASE, but also TTFT, ITL, prefill/decode rows/s,
useful generation TPS, per-phase batch width/fill, runnable/blocked, per-host GPU samples and resource
snapshots in the same analysis window, and real 3-host shard/KV/stage/transfer evidence. A missing field makes the run INVALID, not RED, and the run is
never reinterpreted as a success.
