## Preparation failures and fixes

In the earlier Windows diagnostic build, `CMAKE_CXX_FLAGS=/utf-8` overrode the default `/EHsc`. That build was not promoted
to a final deployment candidate; `/EHsc /utf-8` was set explicitly instead. CPU was rebuilt into a new `native-cost-cpu-final`.
The initial CUDA results were preserved in `cuda-preliminary-binaries` before any real-model run, and CUDA was reconfigured/rebuilt with the flags and the final patch identity.
The current CUDA real-model evidence comes from the post-fix binary. The binaries/logs of the earlier CPU report were preserved.

The first POSIX archive kept CRLF from applying the patch on Windows, so all four hosts **rejected it at the pre-compile patch seal check**.
A separate LF archive was built, the same native diff SHA was confirmed, and the build ran in new `*-cost-lf` paths.
The first archive and the failed launcher logs were preserved. The source hash oracle was not relaxed.
On Ubuntu, instead of a system install, Git came from a distribution Git deb extracted into `$HOME/p4-release-a-tools`.
No existing remote agent/native process was stopped, and no existing deployment folder was changed.
