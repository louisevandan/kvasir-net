## Executed Steps

1. The event-drive artifact now records `started_unix_ms` alongside the monotonic relative time. This lets the
   check reject remote GPU samples taken from a different run and aligned only by relative time.
2. Added `build-integrity-i0-evidence.py`. It independently checks the artifact/config hash, the order of the three hosts, the 1-second sample grid,
   a 750ms tolerance on absolute capture time, 95% coverage, the exact state of the four resource snapshots, distributed execution, and final
   cleanup.
3. Sealed into the integrity spec the product's deterministic state machine, the fixed seed/schedule, and each fault's request index, output ordinal,
   stage, generation, and delay. The test is not an algorithm search; it is the proof procedure for this pre-run contract.
4. Did a clean checkout of the fixed source bundle on the three remote hosts and rebuilt the release binary with a job count that keeps CPU at or below 70%.
   Transferred the new inspector with the same hash and re-read source, binary, native dependency, host/device,
   link, telemetry, and protected agent state.
5. Added an active-host preflight that, in a single pass, rejects on the task agent's PID, exact command, binary hash, advertised address, listener, topology peer, and pre-LOAD
   native/HF/CLOSE_WAIT = 0.
6. Generated H0 v4 so that it binds by hash the runtime, remote binary/library, model/layout, corpus, materializer, raw evidence builder, and judge,
   then ran the integrated verifier.

## Failures

The initial design review found a gap: the event-drive artifact and the remote GPU samples shared only relative time, so samples from a different run
could be combined. Before any model run, we added a runtime absolute anchor and a two-stage time check, and
pinned this as L073. This defect was caught by the pre-run contract audit, not by a model trial.

One non-interactive direct verification command on Spark exited before the test started because Cargo was not on PATH. Per L050, after switching
to the fixed Cargo path, the formatter and the same Rust tests passed. This is not counted as a product run or a model LOAD round.
