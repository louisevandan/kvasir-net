## Power diagnosis and next steps

The recent unexpected shutdown on Windows had no bugcheck/WHEA/thermal record and coincided in time with a large local Rust build/link burst,
after model execution had ended. There is no sensor data to confirm causality, but the current evidence points more toward unbounded
compile load than toward inference. Since then, the final gate and both real adapters have run remotely with limited jobs.

Transport R1–R9 and small-model conformance of both adapters are complete. The next step is the A-PLAN for the Qwen3.5-122B-A10B 3-shard.
First collect the actual machine snapshot and shared memory pool to remove double charging, then compute per-stage
integer caps for weight/KV/result/scratch and legal cuts. Only after this manifest is within available capacity and the deployment path
across at least 2 physical hosts is fixed, proceed in the order LOAD → normal short → deadline/8wave → cancel/release/readmit.
The full 122B topology, long-form, resident 8, SLO and H0–H7 are not accepted by this report.
