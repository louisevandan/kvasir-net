# linkcpp — final verification summary (2026-07-04)

Hardware: single Windows host, RTX 4080 (16GB) + RTX 3090 (24GB), Docker Desktop
(WSL2, nvidia runtime). Two containers, one GPU each (CUDA-UUID pinned).

## Requirement coverage

| # | Requirement | Status | Evidence |
|---|-------------|--------|----------|
| F1 | Distributed inference over (slow) LAN | ✅ | RPC layer-split = hidden-state boundary transfer; node2 executed graph ops (M0-M1) |
| F2 | Huge model loaded distributed across nodes | ✅ | 32B/18GB split: 4080=10GB, 3090=11GB VRAM (M2) |
| F3 | KV cache owned by the layer-owning node | ✅ | RPC distributes KV with layers (M1/M2) |
| F4 | CPU offload of MoE FFN, per owning node | ✅ | `-ot exps=CPU`: VRAM 6758→3029 MiB (M4) |
| F5 | Parallel execution | ✅ | 13× aggregate throughput B=1→8; distributed 12× (M5) |
| N1 | Track llama.cpp version-ups; same models | ✅ | pinned submodule, near-zero core patch |
| N2 | Same backends (CUDA/Vulkan) | ✅ | CUDA verified; Vulkan is same ggml mechanism |
| N3 | Each node computes its layers → hidden state to next | ✅ | RPC boundary transfer (M1) |
| N4 | Docker runtime | ✅ | dev + cluster compose |
| N5 | Single-machine multi-node testing | ✅ | two containers, one host |
| — | Slow-LAN weight locality (bonus) | ✅ | `-c` cache: cold 11GB → warm 256MiB inter-node (43×) (M2) |
| — | One-command distributed HTTP server | ✅ | `docker compose -f docker-compose.cluster.yml up` → curl :8080 → "red, blue, and yellow" |
