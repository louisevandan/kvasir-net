## 확인한 동작과 경계

- 실제 별도 Python 프로세스로 opaque binary·빈 frame·연속 frame·정확한 상한 크기를 왕복했습니다.
- 잘못된 magic/version/reserved/과대 길이 뒤에 정상 frame을 붙여도 peer의 완성 frame 소비·출력은 0입니다.
- header/body 절단은 payload를 반환하지 않습니다. 과대 길이는 body read 호출 전 거부됩니다.
- 짧은 read/write를 처리하고, partial write·flush·read 실패의 원인을 보존합니다.
  송신 입력 bytes는 그대로이며 실패한 방향을 재사용하지 않습니다. 호출자 소유 stream을 임의로 닫지 않습니다.
- 역할별 production/시험/fixture/도구 폴더는 [폴더 규칙](../../../docs/structure/README.md)에 결속했습니다.
- `git check-ignore --no-index models/weights.bin python/p4hfadapter/models/example/loading/__init__.py`는
  루트 가중치 경로만 출력했습니다. 향후 모델 소스가 무시되지 않습니다.
