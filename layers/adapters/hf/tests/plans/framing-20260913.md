# Local IPC framing verification

Purpose: verify, in a real separate Python process, blocking binary stream framing that does not interpret model semantics.
No model has been selected yet, so only the independent transport part of S4a is brought forward. This is not model worker or Rust bridge verification.

- Environment: Windows, installed Python 3.13.15, standard library only. No model/GPU/P4 changes.
- Run: `python -B scripts/testing/run.py` from the repository root.
- Fixture: `tests/fixtures/framing_peer/main.py`; consumes input with the production receiver and returns it with the production sender.
- Normal: opaque binary, empty payload, consecutive frames, limit boundaries, short read/write, clean EOF.
- Rejection: corrupted magic/version/reserved/size consumes no payload and produces 0 output. Oversized lengths are rejected before the body is read.
- Failure: every header/body truncation, read/write/flush errors, no write progress. The first cause is preserved and the stream is not reused.
- Ownership: an invalid send writes 0 and stays reusable; a partial send preserves the original bytes and must not be retried.
  Stream close and upper-level settlement are the caller's responsibility, and transport success is not interpreted as GPU completion or request release.
- RED: record the failure of the same test runner before implementing the source.
- Mutation: in an independent copy, remove each of the fixes for version, length limit, receive-failure state, send-failure state and closed-read error classification,
  and confirm that the same suite fails. Reproduce with `python -B scripts/verification/framing_mutation/run.py`.
  Preserve the copy's source/test SHA256, the child decoder path and hash, the Python identity, exit codes and full logs.
- Outputs: raw logs and source digests in `artifacts/framing/<run-id>/`; summary in `tests/reports/framing/`.
- Unverified: nonblocking/deadline/forced termination, thread safety, tensor/identity schema, reservation ledger, GPU state return, P4 integration.
