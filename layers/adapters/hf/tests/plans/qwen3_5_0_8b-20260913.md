# Qwen3.5-0.8B 전용 분할 스크립트 검증

목표: 고정된 실제 모델을 노드 계획대로 부분 적재하고 공식 전체 모델과 prefill·decode를 비교합니다.
환경: Windows/CPython 3.13.15, torch 2.14.0+cu130, transformers 5.17.0, 로컬 RTX 4080+3090와 CPU.
모델/설정·상한·판정은 [모델 문서](../../docs/models/qwen3_5_0_8b/README.md)의 고정 계약을 따릅니다.

| 단계 | 실행·기대 결과 |
| --- | --- |
| 가중치 확보 | preparation 명령; 고정 revision 파일 SHA256을 manifest에 결속 |
| 잘못된 계획 | dependency-free suite와 inspect 소비; gap/overlap/모델/revision/양자화/상한 거절 |
| 단일 GPU | 공식 전체 모델과 logits·token 비교, EOS와 다음 요청 재수용 |
| 다양한 cut | 12/12, 5/14/5, 3/1/20에서 실제 별도 프로세스·담당 weight/state만 존재 |
| 장치 | GPU, CPU+GPU, CPU 단독을 별도 정밀도 arm으로 기록 |
| 시나리오 | short, 32-token chunked prefill, 여러 요청 교대·스텝 경계 취소와 나머지 요청 계속 처리 |
| 거절 | 모델-runtime state checks; 잘못된 dtype/shape/position/issue/vision token에 연산·상태 생성 0 |
| 변이 | 독립 복사본에서 plan coverage, tokenizer 반환 계약, 중복 issue 검사, cache local-index 변환 제거 |

전체 matrix는 `scripts/verification/qwen3_5_0_8b/run.py`, 상태 거절은 `scripts/verification/qwen_state/run.py`,
독립 변이는 `scripts/verification/qwen_mutation/run.py`입니다. 각 명령은 모델 환경의 Python으로 실행합니다.
기본 `scripts/testing/run.py`는 표준 라이브러리만 필요한 시험을 소유하며 runtime 시험을 대신하지 않습니다.

logits 판정: atol 0.125, rtol 0.01, greedy token 동일. 허용값은 첫 모델 실행 전에 고정했습니다.
BF16 이기종 arm의 실패는 그대로 보존하고, FP32는 별도 입력/정밀도 arm으로 판정합니다.
worker 실행 실패에서는 최초 오류와 cleanup 오류·완료된 요청의 출력·stage trace를 보존합니다.
admission 실패는 worker를 시작하지 않습니다. 진행 중 요청의 부분 생성 출력 복구는 이 실행기의 보장 범위가 아닙니다.

미수행: P4 retained 소비/원장, 실제 여러 물리 호스트, 멀티모달/MTP, 양자화/압축 kernel,
물리 batching, SLO/throughput 수용. 실제 cache tensor의 전 원소 비교는 별도 후속이며 이번 비교는
반복 logits와 stage별 cache 소유·위치·해제 관측입니다.
