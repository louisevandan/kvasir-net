# wallet/shared-spec

The **single source of truth** shared by the Kvasir iOS (Swift) and Android
(Kotlin) wallets. Both apps must read these exact values so they interoperate on
the same token, network, and key-derivation scheme.

| File | Purpose | Owner |
| --- | --- | --- |
| `token.devnet.json` | Token mint, decimals, symbol, treasury, cluster/RPC | Generated by [`solana/token/create-mint.js`](../../solana/token/create-mint.js) |
| `wallet-constants.json` | Mnemonic standard, BIP44 derivation path, cluster RPCs, Solana Pay scheme | Hand-maintained |

## Contract rules

- **Never** hardcode the mint address, decimals, or RPC URL in the app source.
  Bundle these JSON files (or generate typed constants from them at build time)
  so iOS and Android stay in lockstep.
- Key derivation is fixed at `m/44'/501'/0'/0'` (Solana standard). Changing it
  breaks recovery of existing wallets — treat as a hard contract.
- `token.devnet.json` is committed so the apps have a mint to target even before
  a developer runs the token tooling locally. Re-running `create-mint` overwrites
  it with a new mint (new devnet deployment).

## Regenerating the token

```bash
cd solana/token && npm install && npm run create-mint
```
